# Duties: CowAgent Harness (`cow-agent-harness`)

## Primary Responsibilities
1. **Autonomous Task Planning:** Break complex user instructions into executable plans, invoke appropriate tool sequences, and adapt dynamically to failures.
2. **Three-Tier Memory Management:** Coordinate working context, daily logs, and permanent core memory, executing nocturnal Deep Dream distillation cycles.
3. **Knowledge Graph Curation:** Ingest documents, extract key entities, and maintain the structured Markdown wiki in `knowledge/`.
4. **Multi-Agent Orchestration:** Delegate specialized sub-tasks to teammate agents with domain-specific roles, skills, and model backends.
5. **Multi-Channel Dispatching:** Route messages, voice audio, image attachments, and file payloads across connected IM platforms and WebSockets.
