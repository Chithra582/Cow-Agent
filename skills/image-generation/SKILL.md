# Image Generation

Generate and edit images using AI models. The script automatically picks a backend based on which API keys are configured.

## Overview
- Supports OpenAI DALL-E, Google Imagen, Midjourney/Flux, and local diffusion models.
- Generates images from natural language descriptions.
- Supports image-to-image editing, inpainting, and variations.
